 TripleTen - Projeto Homeland

## Descrição do projeto

Este projeto foi desenvolvido como parte do curso de Desenvolvimento Web da TripleTen.

A página apresenta uma galeria de lugares de origem de diferentes colaboradores, incluindo Criccieth, Berea, Muramvya e Rio de Janeiro.

O objetivo principal do projeto foi desenvolver uma página responsiva que se adapte a diferentes tamanhos de tela, seguindo o design disponibilizado no Figma.

## Tecnologias utilizadas

- HTML5
- CSS3
- Metodologia BEM
- BEM Flat
- CSS Grid
- Flexbox
- Media Queries
- Design responsivo
- Git e GitHub

## Responsividade

O projeto foi desenvolvido para funcionar em diferentes resoluções, incluindo:

- Desktop
- 768px
- 320px

Foram utilizadas Media Queries para adaptar o layout, as imagens, os textos e outros elementos da página para diferentes tamanhos de tela.
